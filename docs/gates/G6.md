**A defect it exposed, fixed test-first.** The replay guard (`cli.require_recorded_policy`) looked up the primary model's entry for a run that the fallback had rescued. Such a run decides at the fallback's policy, so a valid replay was refused. This was latent on the global library too. The guard now compares the deciding model's entry, and a new unit test fails without the fix.
